🖼️ VisionRestore AI

Plataforma de Restauración PDI

Aplicación web interactiva y 100% offline diseñada para la restauración matemática de imágenes digitales (documentos y retratos). Desarrollada como proyecto de tesis para la Tecnicatura Superior en Ciencia de Datos e Inteligencia Artificial. Su mayor innovación es que no requiere internet ni tarjetas gráficas costosas, funcionando con fluidez en notebooks de bajos recursos.

🚀 Características Principales

100% Privado y Local

Las fotos nunca salen de tu computadora. No se usan APIs externas ni servicios en la nube.

Optimización Extrema

Comprime las imágenes a WebP y reduce su tamaño para vistas previas instantáneas, aplicando la calidad máxima solo al descargar.

Auditoría de Alucinaciones

Cuenta con un "Mapa JET" que compara los gradientes matemáticos, demostrando que la aplicación no inventa detalles (uso forense).

Modo Acumulativo

Permite encadenar múltiples filtros (ej. iluminar + remarcar texto + quitar ruido) de forma visual.

📁 Estructura del Proyecto

El proyecto sigue una estricta Arquitectura Limpia (Clean Architecture), separando la interfaz visual del motor matemático.

restaurador-imagenes-ia/
├── frontend/                   # Interfaz visual de usuario
│   ├── index.html              # Estructura de la página web
│   ├── style.css               # Diseño, colores y animaciones
│   └── app.js                  # Lógica interactiva
│
├── backend/                    # Motor principal y servidor
│   ├── requirements.txt        # Librerías necesarias
│   ├── app/                    
│   │   ├── main.py             # Archivo que enciende el servidor
│   │   ├── schemas.py          # Reglas de viaje de datos
│   │   └── routers/process.py  # Enrutador REST
│   │
│   ├── vision/                 # Núcleo de Matemática
│   │   ├── imageio.py          # Conversión de imágenes
│   │   └── filters.py          # Fórmulas de OpenCV
│   │
│   ├── experiments/            # Registros del método científico
│   ├── tests/                  # Pruebas automatizadas (pytest)
│   ├── tools/                  # Herramientas modulares extra
│   └── pipeline/               # Tuberías de automatización
│
└── README.md                   # Este manual
🔍 ¿Por qué hay carpetas que no se usan directamente?

Carpetas como experiments/, tests/, y tools/ no son llamadas por la UI, pero se mantienen por el rigor académico de la tesis. Demuestran la validación de las fórmulas, pruebas de calidad de código y dejan la arquitectura lista para futuras expansiones.

💻 Guía de Instalación (Para principiantes)

Sigue estos pasos para usar el programa en Windows, incluso si no sabes programar.

Requisitos Previos

  1. Descarga e instala Python (marca la casilla "Add Python to PATH" durante la instalación).
  2. Descarga un editor de texto como Visual Studio Code (VS Code).

Paso 1: Preparar el Motor (Backend)

Abre la terminal en VS Code y ejecuta estos comandos uno por uno:

# 1. Entrar a la carpeta del motor
cd backend

# 2. Crear un entorno virtual seguro
python -m venv venv

# 3. Activar el entorno (En Windows)
.\venv\Scripts\activate

# 4. Instalar los motores matemáticos
pip install -r requirements.txt

Paso 2: Encender el Servidor

Cada vez que quieras usar la aplicación, debes encender el motor en tu terminal (con el (venv) activado):

uvicorn app.main:app --reload

Verás un mensaje que dice Uvicorn running on http://127.0.0.1:8000. ¡No cierres esta ventana negra!

Paso 3: Abrir la Aplicación Visual

Ve a la carpeta frontend/ en el Explorador de Archivos y haz doble clic en el archivo index.html. Se abrirá en tu navegador listo para usarse.

🎨 ¿Cómo usar la aplicación?

  1. Subir Foto: Arrastra una imagen o haz clic en "Upload".
  2. Seleccionar Categoría: Haz clic en 📄 Documento o 👤 Retrato para desplegar las herramientas correctas.
  3. Aplicar Filtros: Enciende los interruptores. El programa procesará una versión rápida al instante. Usa el deslizador central para comparar.
  4. Auditar (Opcional): Para comprobar científicamente los cambios, haz clic en "Auditar Gradientes".
  5. Descargar: Haz clic en el botón de descarga para guardar tu foto restaurada en alta resolución.
